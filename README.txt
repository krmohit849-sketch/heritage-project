OUR ROOTS — INDIA-WIDE CULTURAL HERITAGE ARCHIVE
Team: Freshman Coders
Project: Local Cultural Heritage Archive

HOW TO RUN
1. Download and extract the ZIP.
2. Open index.html in a modern browser with an internet connection.
3. Try the search, region/theme filters, story details, contribution form and review panel.

WHAT'S NEW
- Expanded from only Dumraon and Delhi to a pan-India archive.
- Added starter collections for Rajasthan, West Bengal, Kerala and Northeast India, alongside Bihar and Delhi.
- Added photographic imagery to the hero and regional cards (internet required for remote images).
- Added filters for more regions and an All India option.
- Responsive design for desktop and mobile.

FEATURES
- Search and region/theme filters
- Story detail pop-up
- Contribution form and browser-based review panel
- Demo moderation to approve/remove submissions
- User submissions persist in browser localStorage

LIMITATIONS
This is a frontend prototype. It has no shared server/database, real user accounts or actual image upload. The selected image filename is shown only in the review panel. Starter entries are prompts for collecting local knowledge, not verified historical claims. Replace or expand content after checking with contributors and reliable sources. Get permission before sharing photographs or personal stories.
